When the user asks me to explain something, even "visually" or "in detail", I answer in the chat itself, using ASCII diagrams in code blocks, tables and small worked numbers. I do NOT publish an Artifact page or make any other file for it.

**Why:** on 2026-10-08 I made an Artifact page for Q9 (how SFT learning happens) and the user was very angry: "don't create any artifacts… i asked u here only right, then u can reply or explain here itself… idiot to create artifacts everytime i asked for explanations".

**How to apply:** an explanation request means a chat reply. Make an artifact or doc only when the user explicitly asks for a page, artifact or doc. Running small measurement scripts to get real numbers is still fine; show the numbers in the chat.
