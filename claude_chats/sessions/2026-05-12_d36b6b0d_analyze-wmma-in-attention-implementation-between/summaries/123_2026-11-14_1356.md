Hkv : 0`.
   - **2% rule**: mix only when `would_mix * 100 >= mx_min_pct * units_plain` (`BLU_GQA_MX_MIN_PCT`, default 2, 0 = always mix); `units_plain += Hq * ((nP+1)/2)`, `would_mix += (Hq/mxG) * (mxG/2)` per chat with odd nQ; `BLU_GQA_MX=0` off switch.
