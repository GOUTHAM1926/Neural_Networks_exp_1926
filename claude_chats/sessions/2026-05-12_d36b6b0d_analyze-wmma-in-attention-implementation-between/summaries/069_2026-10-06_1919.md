2. Key Technical Concepts:

**Muon bug root cause and fix**
- Root cause: float `atomicAdd` order nondeterminism in TI `muon_sumsq_kernel` (`MuonKernels.cu:77`). It changes the Frobenius norm by 1 ulp, which flips bf16 roundings in Newton-Schulz.
- Fix V1n:
  - per-block partials, then a 1-block fixed-order finalize (`*acc = v`);
  - `kMuonSumsqMaxBlocks = 768`, numel-only grid; 768 < the H200's 792 resident blocks.
- Pushed: TI `a9bc08c` + BluTrain `35df307` on `dist_side_merge_BLUCCL`.

**SFT data format**
- Template "tulu-plain-v1" (option A): `<|system|>\n…\n<|user|>\n…\n<|assistant|>\n{answer}<|endoftext|>`.
- Labels: `inputs = ids[:-1]`, `labels = ids[1:]` masked with 65535; pad input = 50256.
- `valid_counts.bin` (uint32 per row).
- T = 4096 (must be a multiple of 256 and ≤ 4096).

**SFT dataloader vs pretraining loader**
- The pretraining `DataLoaderLite` computes target = the same file shifted by one (`DataLoader.h:507-508` memcpy `tokens + 1`). So it can't mask.
- The SFT loader reads targets from `labels.bin` at the same position, row-aligned, plus valid counts.

**Global denominator**
- loss_micro = (sum of the token losses of valid tokens) / (the whole step's valid tokens over all micro-steps and all GPUs).
- Backward seed changes from 1/GRAD_ACCUM to W, because ZeRO's reduce is op=avg.
- Today's BluTrain is "average of averages" (per-micro mean, then a 1/GRAD_ACCUM seed). That is correct for pretraining (equal token counts) but wrong for SFT (it biases tokens of short answers).
- Example: A = 8 tokens with loss 1.0, B = 2 tokens with loss 4.0.
  - Correct: 1.6, each token 10%.
  - Average of averages: 2.5, with A tokens 6.25% each and B tokens 25% each.
- Per-token gradient = seed × (1/N) × (softmax − one-hot). The scalar loss value is not used in backward.
- Library loss op: `sparse_cross_entropy_loss(logits, targets, int64_t ignore_index = -1, const Tensor* denom = nullptr)` (`LossOps.h:41-43`).
  - Its doc: "denom … must be a 1-element device tensor holding the GLOBAL valid-token count … matching torchtitan".
  - The trainer still calls it with 2 args (`bluscript_zero_ckpt.cpp:2181` val, `:2243` train).
  - Seed `1.0f/GRAD_ACCUM` at `:1874`; `max_lr 0.0012` at `:208`; WSD schedule; `max_steps 8000`; `global_batch 1048576`; B = 8; T = 4096.
