2. Key Technical Concepts:

**Kernels:**
- v62 forward (`GQA_fwd_sm90.cu`): persistent, 132 CTAs × 384 threads (1 producer warpgroup + 2 consumers). Work units are (b, hq, couple of query pairs: pair c with pair nP−1−c). Ping-pong named barriers; an "inactive tail" handshake path. O/LSE stored with plain per-thread stores.
- Vj1d backward (`GQA_bwd_vj1d_sm90.cu`):
  - grid (S/64, Hq, B), 128 threads, 2 CTAs/SM, 64×64 tiles;
  - D rowsum from bf16 O;
  - P recomputed as `ex2(fma(S, scale2, −LSE·log2e))`, stored to shared memory as bf16 and re-read for dS (the bf16-P precision issue);
  - dQ is an fp32 TMA reduce-add (non-deterministic);
  - dK/dV are one-writer bf16 partials per q-head, then `gqa_dkdv_greduce` (deterministic). This is the second precision mechanism: per-head bf16 rounding before the head sum.
- Vj1 (`USE_FLASH=1`): bf16 atomic head sum, non-deterministic.
- v44 (`USE_DETERMINISTIC_DQ=1`).

**Design B:**
- `seg_start[b*T+t]` contract: `seg_start[t] <= t`, and it is t or `seg_start[t−1]`.
- Forward: `n0 = seg_start[pair*128]/128`; border tiles masked; −inf guard in the online softmax.
- Backward: trip count = prefix count of `seg_start[q*64] <= kt*64+63` via `__syncthreads_count`; masked when `q==kt || sSS[63] > k_row0`; `sSS[64]` lives in shared memory.

**Design A:**
- `GqaChatPlan`, host-built per batch. The segments (chats + pad tails) must cover every row; the builder throws otherwise.
- Forward units `{b, t0, L, (cpl<<8)|hq}`, longest first. Backward tiles `{b, t0, L, kt}`.
- Forward: rows offset by t0; segment-relative masks; rows past L not stored; a q-tile entirely past L gets `my_nkv = 0` (inactive tail).
- Backward: rows past L get LSE = +inf and D = 0 (FA2 trick, `flash_bwd_kernel.h:411-413`); the tail key tile uses row-checked stores instead of the TMA store (FA3 `epilogue_bwd.hpp:31,263-268`).
- **A is bit-identical to "segment alone through the dense kernel" for every segment.**

**The race fix:** one `__syncthreads()` after `issue(0)` in Vj1d (both instantiations) and Vj1. Tile-0 sLSE was written by threads 0–63 and read by all warps with no barrier.
