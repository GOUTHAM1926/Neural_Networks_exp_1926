2. Key Technical Concepts:

   **SFT concepts (from the user's docs and verified papers):**
   - The SFT loss is the same as pretraining: token cross-entropy, `L = −Σ log p(y_t|y_<t)`. What changes is label construction: prompt and pad positions are set to an ignore value (65535 in our system, because targets are uint16; PyTorch uses −100 with int64 targets).
   - The superficial alignment hypothesis (LIMA).
   - Pipeline: pretraining → midtraining → SFT → DPO → RLVR/GRPO.
   - Chat templates and special tokens.
   - The denominator: a sum loss, or division by the global count of valid tokens (the Tülu 3 §4.3.2 batch-aggregation issue).
   - Right padding vs packing; packing needs a block-diagonal attention mask and position-id resets.
   - Instruct vs Think SFT data (`<think>` traces).
   - Evaluation suites.
