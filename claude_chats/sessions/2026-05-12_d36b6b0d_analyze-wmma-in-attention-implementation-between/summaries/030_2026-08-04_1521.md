2. Key Technical Concepts:
   - SM90 warp-specialized Hopper GEMM: 1 producer + 2 consumer warpgroups (384 threads), TMA, wgmma/HGMMA, mbarriers, persistent grid-stride scheduling, thread block clusters (CGA).
   - `wgmma_n_pick` widest-first cascade over transcribed N shapes `{256,176,168,144,128,112,96,64,32}`; `nchunk_ok`, `splittable`, `sw_pick_symmetric_mn`, `N_GRAIN = sw_atom_elems(B_SWIZZLE)`.
   - Swizzle atoms in elements: SW128=64, SW64=32, SW32=16, INTER=8 (`sw_atom_elems(bytes) = bytes/2`).
   - `SPLIT_M = (MATOMS % 2 == 0)`; BM=64 → 1 M-atom → N-split FORCED → needs ≥2 chunks.
   - Asymmetric N-split (ceil/floor chunk counts per warpgroup) → divergent loop bound → compiler injects `warpgroup.arrive` → **ptxas C7520** "wgmma.mma_async instructions are serialized ... in divergent path". C7520 is a build-time canary.
   - Split-K: `SPLIT_K` template knob, `blockIdx.z` = slice, exact-K partition (`base = k_iters/S`, first `k_iters%S` slices get +1), fp32 partials in workspace `[slice][batch][M][N]`, alpha/beta/bf16-convert applied exactly ONCE in the reduce.
   - Gating rule: `S = largest pow2 ≤ min(floor(SM_count / output_tiles), k_iters)`.
   - Three reduce strategies: (A) separate deterministic kernel [cuBLAS + CUTLASS `reduce_split_k.h`], (B) CUTLASS turnstile [`ReductionMode::Deterministic`, lock-ordered, S-deep chain], (C) BluTrain map-reduce [single launch, `atomicAdd` on a COUNTER only, last CTA reduces].
   - `cublasLt` config API: `CUBLASLT_ALGO_CONFIG_SPLITK_NUM` (renamed from `..._NUM_CHUNKS` in CUDA 13), `CUBLASLT_ALGO_CONFIG_REDUCTION_SCHEME` (`NONE`/`INPLACE`/`COMPUTE_TYPE`/`OUTPUT_TYPE`).
   - Tile orientation (PROVEN §H27y.25 by mirrored-pair grid probe, 8 TRANSPOSE / 0 DIRECT): **cuBLAS `AxB` == our `BM=B, BN=A`**. §H23's block-count "proof" was invalid (commutative product) and is now retracted in the doc.
   - Cluster orientation: **UNRESOLVED after five methods**.
   - Qwen shape derivation: 29 dense models × 8 projections (Q,K,V,O,Gate,Up,Down,LMhead) × 3 passes → 164 distinct (M,N,K) → 225 cases. Backprop forces: FWD `M=T,N=out,K=in` (NT); BWD-dX `M=T,N=in,K=out` (NN); BWD-dW `M=out,N=in,K=T` (TN). Tokens fixed at 4096.
   - Test criterion: `d = fabs(a-b); lim = tol*fabs(b) + 0.5` — the `+0.5` absolute floor is why huge relative errors on near-zero outputs still PASS.
   - H200: 132 SMs, 60 MB L2, 141 GB HBM, `SMEM_BUDGET = 232448`, `SMEM_STATIC_RESERVE = 1024`.
