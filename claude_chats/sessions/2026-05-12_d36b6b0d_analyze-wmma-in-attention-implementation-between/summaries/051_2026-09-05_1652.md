## 2. Key Technical Concepts

- SM90 warp-specialized Hopper GEMM: producer/consumer warpgroups, TMA, wgmma (`HGMMA.64x128x16.F32.BF16`), mbarriers, thread-block clusters
- **`SUPER_M` (his) == `RASTER_SWIZZLE` (ours, log2 group size)** — supergrouped tile rasterization for L2 reuse. *This was the big win.*
- `MATOMS % NCW == 0` — warpgroup count must divide the M-atom count or the M-split is impossible and the kernel drops to half-width wgmma
- Register budget: `PRODUCER_REGS + NCW*CONSUMER_REGS <= 512`; `USE_REGISTER_SPLIT = (PREG>0 && CREG>0)` so 0/0 disables the assert
- GMMA descriptor encoding: `desc_encode = (x & 0x3FFFF) >> 4`; low bits ARE the address so advancing is an immediate add
- No-swizzle tier (`SwizzleBytes==16`, layout_type 0 INTERLEAVE): **stride and leading bytes are TRANSPOSED** (the reference's `kSwizzleMode==16` case)
- DSMEM address encoding: `0x400 + (cta_rank << 24) + stage*8`
- `SYNCS.PHASECHK.TRANS64.TRYWAIT` = mbarrier spin-wait; ptxas outlines retry back-edges into a tail block
- Uniform vs vector datapath (`U`-prefixed opcodes, `R2UR`, `S2UR` are uniform)
- ncu stall reasons: `long_scoreboard` (global memory), `short_scoreboard` (MIO/shared), `barrier`, `wait`
- Paired ABBA crossover, 12 rounds, **one config per process** (many-in-one deflates some 6–8%)
- `-c` not `-dc`: relocatable device code breaks `__grid_constant__` TMA descriptors and `cudaLaunchKernelEx` cluster launches
- nvcc compiles TUs on one command line **sequentially** — must use one invocation per TU for parallelism
