2. Key Technical Concepts:
   - **CUDA grid limits:** grid y ≤ 65,535. Fixes chosen: tokens in grid x (embedding e1); grid-y cap + row loop (SwiGLU s2).
   - **Fused RoPE backward grid:** `BF16_BWD_T_CHUNKS = 32`, fixed per row → 192 warps at 128k × 1 → slow. Fix pending.
   - **SwiGLU sm120 float4 path:** valid only when hidden % 4 == 0 and pointers are 16-byte aligned; otherwise use the scalar kernel (PyTorch `can_vectorize_up_to`, TransformerEngine aligned/unaligned launch).
   - **Vj2 attention backward:**
     - template `<CHATS, F32P>`;
     - fp32 dK/dV partials switch `BLU_VJ2_DKDV_F32`;
     - `gqa_dkdv_greduce_vj2<bf16|float>`.
   - **run_sft.sh unsets every `BLU_*` variable before mpirun.** To pass a switch, give BIN = a wrapper script.
   - **Library gradient dtype:** bf16 params keep fp32 gradients (`AutogradMeta.cpp:160-163`); read them via `grad_view()`.
   - **lm_head+loss approaches:**
     - TRL `add_fused_lm_head`: `hidden[mask]`, chunked log-prob with recompute, 8·N_t work.
     - Unsloth `fused_linear_ce_v2`: `_keep_index`, gradient in the forward, 6·N_t.
     - CCE: valids gather in the kernel, plus `filter_eps` gradient filtering.
     - Liger FLCE: chunks over all rows, gradient in the forward, 6·N.
     - HF / torchtitan: full logits plus an fp32 upcast.
     - torchtune: chunked output layer and upcast.
     - Megatron: `vocab_parallel_cross_entropy` in fp32 plus `loss_mask`.
     - Ours: full bf16 logits, BluBLAS `bgemm_sm90_kernel`, `sparse_cross_entropy_loss` with an in-place backward.
   - **Shapes:**
     - N = B·T is fixed per T. N_t (trained tokens) varies per micro-batch: 4k median 47,730 / 65,536; 128k median 64,114 / 131,072, min 77.
     - Today: `[N,512]×[512,49280]`.
     - Trained-only: gather `X[idx]` → `[N_t,512]×[512,49280]` → loss with no masking → scatter dX into zeros.
     - Round N_t up to a multiple of 256 with filler rows (BluBLAS sub-64 issue).
   - **CP (Adhitya, cf1372d):**
     - Ulysses combine/partition = all-to-all transforms.
     - Ring split kernels are forks of our v62/v44.
     - Doc mask: ring + split only, ids from EOT, positions not restarted.
     - YARNOps.cpp builds the RoPE table on the CPU, so the TI table bug did not hit CP.
