2. Key Technical Concepts:
   - **Two-stage loss reduction:**
     - stage 2 = one block of 256 threads; the old single load dropped rows ≥65,536;
     - printed loss ≈ true × 65,536/N; gradients unaffected (backward uses saved max/sum + denom).
   - **B2 fix:** single load when `gridDim*blockDim >= n`, else a 64-bit strided loop; bit-identical ≤65,536.
   - **Measurement tools and methods:**
     - CPU emulation of exact fp32 summation orders;
     - nsys GPU kernel time vs wall-clock (launch-bound);
     - ABBA/null arms;
     - SASS diff (`cuobjdump`);
     - compute-sanitizer;
     - `cudaMemGetInfo`.
   - **Dynamic linking:** `libtensor.so` is loaded via `LD_LIBRARY_PATH` (RUNPATH `$ORIGIN`-relative), so one trainer binary can be A/B tested with two libraries.
   - **P022 GPUs are Exclusive_Process** (one process per GPU); Aparna's 8-GPU jobs collide.
   - **Packing:** FFD (First-Fit-Decreasing, max segment tree); `seq_lengths` / `seq_offsets`; positions restart per chat; design-A varlen attention.
   - **TRL `bfd_split`** (verified in code):
     - cuts every `seq_length` tokens; nothing inserted at a cut;
     - each piece gets its own `seq_lengths` entry; positions restart; first token label −100.
     - bfd truncates; wrapped mixes chats. Megatron truncates and drops later conversations; torchtitan drops.
   - **`split_turns` 4 cases:**
     1. fits;
     2. cut between turns, with earlier turns as untrained context;
     3. cut inside an answer: no end token; continuation repeats system + question + assistant marker + answer tail as untrained context (≤ `ctx_frac` × T); the next turn joins;
     4. question too long for the budget → that turn and later turns left out.

     Every answer token is trained once; pieces are copies of the original ids.
   - **`seq_complete.bin`:** uint8 per chat; 0 = piece cut mid-answer; the loader skips the end-token check only for 0.
   - **Memory:**
     - constant = weights, gradients, optimizer states, context;
     - variable = activations ∝ tokens per GPU (B×T), plus logits B×T×V.
     - CP is needed only when ONE row of length T doesn't fit one GPU.
     - CP = split one row across GPUs (Ulysses / ring); if needed later, wire Adhitya's CP attention / RoPE kernels and keep the other kernels.
   - **Context extension** (YaRN / Position Interpolation) before SFT at a longer T.

     ```cpp
     unsigned int tid = threadIdx.x;
     // One value per thread while the grid covers n ... The loop sits behind the branch because an
     // always-on loop cost ~0.3 us per call (nsys, H200).
     const int64_t i0 = blockIdx.x * (int64_t)blockDim.x + tid;
     const int64_t stride = (int64_t)gridDim.x * blockDim.x;
     float v = 0.0f;
     if (stride >= n) {
       if (i0 < n) v = static_cast<float>(input[i0]);
     } else {
       for (int64_t i = i0; i < n; i += stride) v += static_cast<float>(input[i]);
     }

     __syncthreads();
     ```
