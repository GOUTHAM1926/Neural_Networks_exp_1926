2. **Key Technical Concepts:**
- SM90 warp-specialized Hopper GEMM: 1 producer + 2 consumer warpgroups, TMA, wgmma/HGMMA, mbarriers, thread-block clusters
- **PDL (Programmatic Dependent Launch)**: next kernel's blocks launch early then block on `cudaGridDependencySynchronize()`; producer signals via `griddep_launch_dependents()`. Kill switch: `getenv("blublas_NO_PDL") != nullptr` (ANY value disables, including `=0`)
- `WGMMA_SKEW`: carries atom 0 across the loop back-edge; sole cause of C7517/C7519; requires ≥2 m64 atoms per warpgroup (static_assert blocks 128x256/128x128)
- §H27z.86 swap rule: cuBLAS `AxB, r` → ours `BxA, flip(r)`
- Dispatcher: tier-1 binary search on (M,N,K) lexicographic → tier-2 fitted tree → `call_XX(cfg,...)` switch
- ncu vs nsys: **ncu isolates/serializes each kernel; nsys measures launch-to-completion span in situ** — this distinction resolved the whole investigation
- Measurement traps: multi-config-per-process deflation (≥2 predecessors), SIGPIPE+pipefail with `grep -q`, mpirun only forwards `-x`-named env vars
