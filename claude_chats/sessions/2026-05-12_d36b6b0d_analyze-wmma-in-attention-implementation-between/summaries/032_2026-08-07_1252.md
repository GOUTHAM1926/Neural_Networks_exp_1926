## 2. Key Technical Concepts

- SM90 warp-specialized Hopper GEMM: 1 producer + 2 consumer warpgroups, TMA, wgmma/HGMMA, mbarriers, thread block clusters
- `cuTensorMapEncodeTiled` constraints: `boxDim[0]*elemSize % 16 == 0`; globalStride multiple of 16 bytes (%8 for bf16)

- `__grid_constant__` TMA descriptor kernel params

}
