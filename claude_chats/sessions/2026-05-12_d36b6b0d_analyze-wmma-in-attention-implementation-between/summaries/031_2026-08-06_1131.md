2. Key Technical Concepts:
   - SM90 warp-specialized Hopper GEMM: 1 producer + 2 consumer warpgroups, TMA, wgmma/HGMMA, mbarriers, persistent grid-stride scheduling, thread block clusters.
   - `cuTensorMapEncodeTiled` constraints: `boxDim[0]*elementSize % 16 == 0`; `globalStride` must be a multiple of 16 bytes → for bf16 that is `%8` on any dimension used as a stride.
   - Per-layout MN-major rule: `A_MN = (Layout==TN)`, `B_MN = (NN||TN)` → **M is unconstrained in NN/NT**, required `%8` only in TN.
   - Wave quantization: `tiles/SM_count`; a 256x128 tile on a 512x768 output gives 12 tiles for 132 SMs (9% occupancy).
   - Split-K: `SPLIT_K` template knob, fp32 partials in workspace `[slice][batch][M][N]`, deterministic fixed-order reduce, alpha/beta applied once.
   - `setmaxnreg` register split: must be the literal first statement inside each warpgroup branch, before any shared prologue (`__syncthreads`, mbarrier init, TMA prefetch), else ptxas emits C7507 "setmaxnreg ignored".
   - Decision-tree fitting in log space; geometric-midpoint thresholds converted back to integer comparisons at generation time.
   - 5-fold cross-validation / leave-one-out for honest out-of-sample selection loss.
   - BluTrain build chain: `BluTrain/Makefile` → `Tensor-Implementations/Makefile` (compiles BluBLAS sources itself into `libblublas.so`) → `BluBridge-BLAS/src`.
   - `is_blackwell_src` markers (`SM100 SM103 B300 sm100 sm103 b300`) + `GENCODE_BLACKWELL` cross-compilation.
   - H200: 132 SMs, 141-143 GB HBM, CUDA 13.0.
