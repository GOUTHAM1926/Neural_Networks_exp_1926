2. **Key Technical Concepts:**

- **SFT = same next-token cross-entropy as pretraining; only label masking changes**
- **`ignore_index` semantics** — PyTorch ATen and Liger both use a single `int64_t ignore_index` with NO boolean flag
- **Sentinel choice**: targets are `uint16` (range 0–65535), vocab is 50304, so 50304–65535 is unused → sentinel **65535**. PyTorch's `-100` is impossible (uint16 stores it as 65436). Default `-1` matches nothing = safe "off"
- **NaN trap**: `saved_sum`/`d_partial_sum` sentinels must be `1.0f`, never `0.0f` — backward computes `1/sum`, giving `inf`, then `inf*0 = NaN`
- **OOB trap**: forward kernels do `row_logits[target_idx]`; target 65535 on vocab 50304 reads 15,231 elements past the row. The early-out is therefore CORRECTNESS, not optimisation
- **Block-uniform branches**: guard depends only on `blockIdx.x`, so all threads take the same path — no `__syncthreads()` deadlock possible
- **C++ default-argument rules**: default may be written exactly ONCE (header, not .cu); defaults must be TRAILING (after `cudaStream_t stream`)
- **Explicit instantiation macros** must list new types or code compiles and fails at LINK per-dtype
- **Submodules store a commit SHA (mode `160000`), not files** — parent tracks 0 files inside; needs its own branch
- **Denominator options**: (A) constant batch_size = uniform weighting; (B) global N all-reduced = exact; (C) local n_i per micro-batch = 13.5× distortion. Megatron's DEFAULT is (C); torchtitan uses (B)
- **torchtitan's design**: `reduction="sum"`, prefetch all micro-batches, sum `num_valid_tokens` from the collator, `dist_sum_tensor` all-reduce, pass one device tensor; `loss = loss / global_valid_tokens`
- **`accscalar_t` pattern**: `CUDA_ACC_TYPE(BFloat16, float)` — PyTorch accumulates in fp32, divides in fp32, casts to `scalar_t` ONCE at the end (`Loss.cu:266`)
- **bf16 error is RELATIVE** (~0.4%), so casting 20443 or 2.4955 costs the same
- **RTX 3060 = sm_86**; SM90 BLAS kernels (`.tensormap`, `griddepcontrol`, `cp.async.bulk`) cannot compile for sm_86
