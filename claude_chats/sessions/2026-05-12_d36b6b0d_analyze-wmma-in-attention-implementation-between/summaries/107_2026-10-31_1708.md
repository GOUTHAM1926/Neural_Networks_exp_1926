2. Key Technical Concepts:

   - **CUDA grid limits:** grid x up to 2^31−1; y and z up to 65,535. Fix patterns:
     - token/row in grid x (RoPE v1, loss l3);
     - grid-y loop;
     - flat 1-D grid-stride with a 64-bit index;
     - PyTorch `TensorIterator::with_32bit_indexing` split (Loops.cuh:97-98);
     - FlashAttention `index_t = int64_t`;
     - Liger int64 program_id;
     - TransformerEngine 1-D size_t grids.
   - **32-bit element-index overflow** past 2^31/2^32: logits = T × 49,280 (6.46e9 at 131k).
   - **`--use_fast_math`:** per-file flag via a Makefile target-specific variable; `__expf` vs exact `expf`; ftz.
   - **TMA bulk stores:**
     - `cp.async.bulk.wait_group 0` (bulk_wait_all) vs `.read 0` (bulk_wait_read = CUTLASS tma_store_wait);
     - SWIZZLE_128B: fp32 box {32,64}, chunk k ^ (r&7).
   - **Vj2 attention backward:**
     - one-writer bf16 dK/dV partials per query head, plus `gqa_dkdv_greduce_vj2` fixed-order fp32 head sum (deterministic);
     - FA3: fp32 accumulators with TMA bulk reduce-add (non-deterministic; deterministic mode uses semaphores, +31%).
   - **G14 test:** real packed rows vs fp64, floor-based ratio (limit 2× floor). G2 = dense rows. G4 = repeat test (bitwise).
   - **Memory model:** peak ≈ 8,402 MiB + 0.757 MiB × tokens (B × T).
   - **SftDataLoader:** refuses splits smaller than one micro-batch (SftDataLoader.h:95). run_sft.sh takes T from meta.json, ignores BLU_MAX_STEPS in SFT mode, and sets BLU_EMB_BWD=segmented and BLU_ALL_BF16=1.
   - **BluCCL embedding backward** (comm::fusion::embedding_bwd_*): no grid-y limit.
