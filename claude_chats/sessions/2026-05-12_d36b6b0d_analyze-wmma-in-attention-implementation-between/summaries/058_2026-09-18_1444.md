2. **Key Technical Concepts:**

- **SFT (Supervised Fine-Tuning)** — uses the *identical* next-token cross-entropy loss as pretraining; what changes is label construction (masking), not the loss
- **Label masking** — `-100` (PyTorch's `ignore_index` default) or a sentinel; loss computed only on assistant/completion tokens
- **The 3-stage pipeline** — pretraining → mid-training → post-training (not 2 stages)
- **Self-supervised vs unsupervised** — pretraining is self-supervised (labels come free from the data)
- **Mid-training** — term from an OpenAI job description mid-2024; hundreds of billions of tokens; data quality shift, long-context extension, prepares RL
- **Post-training contents (6)** — SFT, preference/RL, distillation, model merging, safety tuning, quantization/QAT
- **SFT-then-RL order** — DeepSeek R1-Zero (pure RL) had poor readability/language mixing/instability; R1 added cold-start SFT
- **DPO** — `L_DPO = −E[log σ(β(log π_θ(y⁺|x)/π_ref(y⁺|x) − log π_θ(y⁻|x)/π_ref(y⁻|x)))]`; needs a frozen reference model; 4 forwards/step; default LR 1e-6
- **GRPO** — group-relative advantage `Â_i = (r_i − mean(r))/std(r)`; generates 8 completions during training; needs vLLM; importance-sampling correction for train/inference kernel mismatch
- **TRL** = Transformer Reinforcement Learning (HuggingFace), post-training only, v1.13.0
- **torchtune** — DISCONTINUED 2025, replaced by **torchforge**
- **Packing** — BFD bin packing; requires per-token position_ids reset and varlen/cu_seqlens attention
- **Chunked cross-entropy** — TRL's default `loss_type="chunked_nll"`; skips ignored-label tokens in lm_head projection
- **BluBLAS/4B findings** — 99.80% of cuBLAS at production schedule; 15 shapes, 8 GEMM variants, 1,267,280 launches; `BLU_MAX_STEPS` regime effect is BLAS-specific
