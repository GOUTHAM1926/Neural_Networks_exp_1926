2. **Key Technical Concepts:**
- SM90 warp-specialized Hopper GEMM: producer/consumer warpgroups, TMA (`UTMALDG.3D`), `wgmma`/`HGMMA`, mbarriers, thread-block clusters
- **Vector vs uniform datapath**: `IMAD`/`IADD3`/`LOP3`/`SHF`/`ISETP`/`LEA` (per-thread, 32 lanes) vs `UIADD3`/`ULOP3`/`USHF`/`UMOV`/`ULEA`/`UIMAD` (uniform, 1 lane). `R2UR`/`S2UR` = crossings.
- **A vector op drives 32 lanes; a uniform op drives one** — hence total instruction count is the wrong metric
- `P = α·C·V²·f` — α is the activity factor (only term code controls); at a fixed power cap, higher α forces lower f
- TMA multicast: `NEEDS_A_MULTICAST = MULTICAST_A && (CLUSTER_N > 1)`, `NEEDS_B_MULTICAST = MULTICAST_B && (CLUSTER_M > 1)`; cooperative K-slicing via `A_MN_SLICE_K = BK/CLUSTER_N`, `B_MN_SLICE_K = BK/CLUSTER_M`
- ncu metrics: `lts__t_requests_op_read.sum`, `lts__t_sectors_lookup_hit/miss`, `lts__t_requests_srcunit_tex_op_read`, `sm__inst_executed_pipe_uniform`, `sm__pipe_tensor_cycles_active.avg.pct_of_peak_sustained_active`
- `power.draw` is a **2.4 s trailing average**; `power.draw.instant` is correct but **aliases above ~5 Hz**; persistence mode must be on or the sensor sticks
- Sign test across independent shapes is the right instrument for sub-floor effects (paired floor was 1.37 points)
