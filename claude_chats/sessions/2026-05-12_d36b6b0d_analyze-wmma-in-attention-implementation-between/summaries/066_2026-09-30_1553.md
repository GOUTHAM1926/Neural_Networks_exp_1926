2. Key Technical Concepts:
- Weight tying: one parameter `wte.weight` [50,304 × 2,304] used twice:
  - the input lookup (gather, not a matmul);
  - the output lm_head matmul (`logits = h × wte^T`).
- Lookup backward = a scatter-add per token (sum of K position-gradient vectors).
- bf16 `atomicAdd` (a rounding per add, non-deterministic order) vs the fp32 cooperative kernel (no atomics, fixed order).
- `ToDtypeBackward`: converts the gradient back to the source dtype. The Engine sums multiple gradients for a leaf.
- `transpose` = a view; `contiguous` = a copy. The lm_head bf16 transposed copy is rebuilt every micro-step (63/64 redundant).
- Matmul backward produces 2 gradients (one per input).
- ZeRO-1 v1 (`ShardedOptimizer`) flow:
  - `gather_grads_into_flat` (fp32 → bf16 into `flat_stage_`) → `reduce_scatter_grads` (a copy at W=1) → `cast_shard_grad_to_fp32` → Adam → `all_gather_params` (fp32 → bf16) → `scatter_flat_into_params`.

  10. `to_dtype(logits, logit_dtype)`
  11. loss

  - the logits `ToDtypeBackward`;
  - MatmulBackward (2 outputs: grad_h [32,768 × 2,304] and grad_w_t [2,304 × 50,304]);
