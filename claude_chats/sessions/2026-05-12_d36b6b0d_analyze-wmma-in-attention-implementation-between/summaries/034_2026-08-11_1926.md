2. **Key Technical Concepts:**
- SM90 warp-specialized Hopper GEMM: 1 producer + 2 consumer warpgroups, TMA, wgmma/HGMMA, mbarriers, thread block clusters
- `stmatrix.sync.aligned.m8n8.x4.shared.b16` → SASS `STSM.16.M88.4`; requires sm_90+; two distinct lane groupings (address by `t/8`, data by `t/4`)
- wgmma fp32 accumulator `CLayout_64xN`: `row = t1 + 8*v1 + 16*t2`, `col = 2*t0 + v0 + 8*v2`, with `reg_idx = v0 + 2*v1 + 4*v2`
- TMA swizzle: `CU_TENSOR_MAP_SWIZZLE_128B/64B/32B` = "swizzle 16B chunks within N-byte span"; `boxDim[0]*elemSize <= swizzle size`
- Measured swizzle permutations: SW128 `g ^ (row&7)`, SW64 `g ^ ((row>>1)&3)`, SW32 `g ^ ((row>>2)&1)`; unified `granule ^= (row >> (3 - log2(SPAN))) & (SPAN-1)`
- SPLIT_M = `(BM/64) % 2 == 0`; determines M-split vs N-split, which determines whether chunked epilogues pay
- Split-K strategy (A): separate deterministic reduce pass, fp32 workspace, no atomics, alpha/beta applied exactly once
- cuBLAS operand swap: `cublasGemmEx(handle, opB, opA, N, M, K, ...)` → their BM×BN is our BN×BM, CX×CY is our CY×CX, raster flips
- Hopper **uniform datapath** (URx registers, `UIMAD`/`UIADD3`/`USHF`/`UISETP`/`ULDC`) runs in parallel with the vector datapath
- Magic-number (reciprocal) division: CUTLASS `find_divisor`/`fast_divmod`
- ncu metrics: `l1tex__data_bank_conflicts_pipe_lsu_mem_shared_op_st.sum`, `lts__t_sector_hit_rate.pct`, `dram__bytes.sum`, `sm__pipe_tensor_cycles_active`, `smsp__inst_executed.sum`, `launch__shared_mem_per_block_dynamic`

void find_divisor(unsigned int& mul, unsigned int& shr, unsigned int denom) {
  if (denom == 1) { mul = 0; shr = 0; }
  else {
    unsigned int p = 31 + find_log2(denom);
    unsigned m = unsigned(((1ull << p) + unsigned(denom) - 1) / unsigned(denom));
    mul = m; shr = p - 32;
  }
}
void fast_divmod(int& quo, int& rem, int src, int div, unsigned int mul, unsigned int shr) {
  quo = (div != 1) ? __umulhi(src, mul) >> shr : src;
  rem = src - (quo * div);
}
value_t find_log2(value_t x) {
  int a = int(31 - clz(x));
  a += (x & (x - 1)) != 0;  // Round up, add 1 if not a power of 2.
  return a;
}
