2. Key Technical Concepts:
   - **Our forward kernel** (`GQA_fwd_sm90.cu`, Hopper, head dim 128): work unit = segment (chat) x query head x couple of pairs; pair = two 64-row query tiles, one per consumer warpgroup; odd number of 64-row tiles leaves the second group idle. Plan (`GqaChatPlan`) built on CPU once per micro-batch by `gqa_chat_plan_build` (in `GQA_fwd_generic.cu`).
   - **MX ("mixed units")**: the idle group runs the same last tile of another query head of the same KV head. Unit word `w`: bit 31 = mixed unit (group 0 head `w & 0xff`, group 1 head `(w >> 8) & 0xff`, tile index ceil(L/64)-1); bit 30 = plain couple with nP = ceil(L/128)-1, cpl = `(w >> 8) & 0x3fffff`. Third kernel instantiation `MODE_CHATS_MX = 2`; `MODE_DENSE` and `MODE_CHATS` machine code unchanged (SASS diff by `cuobjdump -sass`, 0 lines, laptop CUDA 13.0 and P032 CUDA 13.4); MX kernel = raced candidate (0 lines). `GqaChatPlan::mx_hkv`; `gqa_chat_plan_build/make(..., Hq, Hkv = 0)`; forward dispatcher refuses a plan with another KV-head count; `BLU_GQA_MX=0` off switch.
