**2. Key Technical Concepts**
- **CUTLASS schedules:**
  - ping-pong: each consumer owns its own tile; MathWarpGroupOrderBarrier = OrderedSequenceBarrier → ClusterBarrier (mbarrier → SASS SYNCS);
  - cooperative: also 40/232 setmaxnreg, so the register split is not a ping-pong marker;
  - FA3 ping-pong is a different thing that shares the name.
- **GEMM epilogue fusion vs fp32 output:**
  - casts happen in registers (0 cast kernels measured);
  - fp32 output doubles the bytes for memory-bound next ops;
  - fusion removes the intermediate round trip and one rounding.
- **BluBLAS SM90 template:** `Sm90WarpspecConfig<BM, BN, BK, ..., PRODUCER_REGS, CONSUMER_REGS ...>`, regsplit 24/240, BiasMode 4 = full M×N TMA bias, HasBeta epilogue reads C without prefetch.
- **Autograd:**
  - `MatmulBackward` / `AddmmBackward` → `cuda_matmul_backward` (launch_backward_matmul with beta_a / beta_b);
  - the engine sums input grads (`Engine.cpp:343`);
  - `AutogradMeta::accumulate_grad`;
  - `GradAccumulator::apply` calls accumulate_grad, then `trigger_post_acc_hooks(meta->grad())`.
- **ZeRO:**
  - BLU_GRAD_VIEW: gradient slots are bf16 views into flat_grad_; zero_grad memsets the buffer;
  - declined at world size 1;
  - at W=1 the update reads grads via `prepare_direct_grads` / `owned_grad_fp32` in their own dtype.
- **nsys:** NVTX ranges via `BLU_NVTX=1`; sqlite tables CUPTI_ACTIVITY_KIND_KERNEL / RUNTIME, NVTX_EVENTS, GPU_METRICS.
