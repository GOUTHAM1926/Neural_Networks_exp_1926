2. Key Technical Concepts:
   - **Gradient accumulation:** GRAD_ACCUM = global_batch 1,048,576 / (B=4 × T=4096) = 64 micro-steps per optimizer step.
   - **AutogradMeta::accumulate_grad:** keeps an fp32 `grad_` ("main_grad") for bf16 weights.
     - `update` = the new bf16 grad from MatmulBackward (MatrixBackward.cpp:87, `Tensor grad_b(saved_b_.shape(), saved_b_.dtype(), ...)`).
     - It reaches accumulate_grad through GradAccumulator.cpp:51.
   - **Old line 173:** `*grad_ += update.as_type(grad_->dtype());` creates a full-size fp32 temporary. Traffic is 18 B per element and 2 kernels; F2 makes it 10 B per element and 1 kernel.
   - **zero_grad fills with zeros (does not delete):** ShardedOptimizer.cpp:1339-1348, rec.param.zero_grad(). So every micro-step takes the += path.
   - **ZeRO-1 v1 bf16 wire:** compute_dtype_ = param dtype (bf16), ShardedOptimizer.cpp:179-184.
     - gather converts fp32 grad → bf16 flat_stage_ (:963/:548), then reduce_scatter/copy, then cast_shard_grad_to_fp32 (:994).
     - Fix #2 (25 Sept) removed temporaries there. F4 (the bf16 round trip at W=1) is a separate open item.
     - Possible "F2b": set_to_none instead of zero-fill.
   - **Model shape:** d_model 2304, ffn 6144, 26 layers, 6 bf16 weights per layer (wQ, wK, wV, wO, gate_up, down).
     - 156 bf16 tensors, 56,623,104 numbers per layer, 1,472,200,704 in total.
     - The largest temporary is gate_up: 2304×12288×4 B = 108 MiB.
     - Peak memory can drop by at most 108 MiB, because temporaries are sequential. The 5.9 GB is traffic, not simultaneous memory.
   - **Compile flags:** --use_fast_math gives FADD.FTZ in both the old and new kernels; bf16→fp32 widening is exact (shift), fp16→fp32 is exact (HADD2.F32).
   - **v62:** the Hopper causal GQA forward kernel, hd=128. It needs T % 256 == 0 (GQA_fwd_generic.cu:35-47); otherwise BluTrain throws "causal attention is only implemented for head_dim 64".
   - **Backends:** the root Makefile has WITH_BLUBLAS ?= 0 (cuBLAS). The 24 Sept trainer recipe uses WITH_BLUBLAS=1; tests then need MAKE_ARGS="WITH_BLUBLAS=1".
   - **Build:** BluTrain root targets `profiler` and `tensor`. The trainer is built with `make build-mpi FILE=bluscript_zero_ckpt.cpp WITH_BLUBLAS=1 -j$(nproc)` and produces `_runner_`.
