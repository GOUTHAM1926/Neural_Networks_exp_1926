2. Key Technical Concepts:

**Muon optimizer (ShardedMuon, ZeRO-1)**
- 222 matrices on the 135M model: 37 layers × wq, wk, wv, wo, gate_up, down.
- Per-matrix chain: weight decay → momentum → Newton-Schulz → guard → nsratio → apply. About 28 kernels per matrix, ~6,200 kernels per step.
- Newton-Schulz: bf16, 5 iterations of `A = X Xᵀ`, `B = c·A·A + b·A`, `X = a·X + B·X`, with a = 3.4445, b = −4.7750, c = 2.0315.
- Tall matrices are transposed first.
- Frobenius scale is a deterministic two-pass reduction (`kMuonSumsqMaxBlocks` = 768).

**Batched Newton-Schulz**
- Others: Megatron `ns_batch_size` (default 1 = bit-exact), Dion mega-batch, modded-nanogpt banks with Triton symmetric kernels and CUDA graphs, NeMo baddbmm, torchtitan ("bitwise equality ... not part of the contract").
- Our cap is a memory budget, `BLU_MUON_NS_BATCH_MB` (default 512; 0 = off). A chunk of 1 uses today's code.

**BluBLAS addmm**
- SM90 fused epilogue: `alpha·acc + beta·bias`, one rounding. Bias modes: Runtime, Scalar, PerCol, PerRow, Full, plus the new FullBatched.
- Old fallback: `bgemm_scale_template_kernel` (`C = beta·C_old + bias`) then a beta = 1 GEMM. Bug: `alpha·AB + beta·C_old + bias`.

**PyTorch addmm (Blas.cpp)**
- `beta ≠ 0`: copy the input (broadcast) into the result, then one GEMM with beta.
- `beta == 0`: the input is ignored; "nans and infs should not propagate".
- cuBLASLt bias epilogue only when `beta == 1`.
- cuBLAS: "If beta == 0 then C does not have to be a valid input".

**Proofs and tools**
- SASS fingerprinting: `cuobjdump -sass`, md5 per kernel with addresses stripped.
- `git apply --check` on clean worktrees.
