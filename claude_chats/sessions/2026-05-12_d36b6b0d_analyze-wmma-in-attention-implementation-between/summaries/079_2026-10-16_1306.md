2. Key Technical Concepts:

**Design A (seqlens/per-chat list) vs B (segstart, removed).**
- Plan = GqaChatPlan:
  - fwd_units `{b,t0,L,(cpl<<8)|hq}`;
  - Vj1d bwd_tiles `{b,t0,L,kt}` (64 keys);
  - Vj2 vj2_blocks `{b,t0,L,kt,hq,dqt0,0,0}` (128-key tiles × heads, LPT in sections of `gqa_vj2_section_pairs(S)`);
  - dq_tiles `{b,row0,nrows,0}`: padded 64-row slots, like FA3's offset_padded;
  - one allocation (`storage`) with one cudaMemcpyAsync on the current stream;
  - shared handle `GqaChatPlanPtr` (`std::shared_ptr<const GqaChatPlan>`) via `gqa_chat_plan_make`.
- Vj2 CHATS mode:
  - segment-relative indices;
  - padded LSE/D/dQacc filled by `bwd_prep_vj2_chats` (rows past L: LSE2=+inf, D=0);
  - `convert_dq_frag_vj2<true>` writes slots back to token rows;
  - the last key tile stores only rows < L with plain 16-B stores from the SW128-swizzled staging.

**Data format.**
- `seq_lengths.bin` (int32, TRL seq_lengths) + `seq_offsets.bin` (int64 [N+1]).
- The pad tail is added by the loader as its own segment.
- RoPE positions restart at 0 per segment.
- The loader refuses old seg_start-only folders.

**Tile waste (§45.9).**
- Design A computes 1.13× the real pairs, against B's 1.20× and v1's 9.15×.
- A's forward waste is 11.54% of computed pairs: 7.48% in diagonal tiles, 3.83% at chat ends, 0.23% in pad tails.
- Seqlens wins on middle/long chats: in B, every query block of a chat reaches back to the chat's first key block, which is shared with the previous chat. Segstart wins on tiny chats: whole block per tiny chat, plus a fixed per-piece cost.

**Determinism.**
- Ours: v62 forward fully deterministic; Vj2 dK/dV deterministic (one writer per query head + fixed-order head sum); dQ not (atomic bulk reduce-add).
- FA3 forward: one version, deterministic. The `deterministic` flag exists only in `_flash_attn_backward` (`flash_attn_interface.py:259-280`).
- FA3 normal backward with GQA: dQ and dK/dV non-deterministic (`CollectiveEpilogueBwdGQA` atomicAdd, `epilogue_bwd.hpp:323, 458-491, 480`; `flash_bwd_launch_template.h:92-94, 138-153`).
- FA3 deterministic mode costs about 1.22× FA3's time.
- v44 (`USE_DETERMINISTIC_DQ=1`) is a whole older backward kernel with bit-identical dQ, dense only.

**Benchmarking.**
- Free clocks; power cap 700 W (a faster backward lowers the next forward's clock).
- Our runs interleaved around the libraries; noise about 1%.
