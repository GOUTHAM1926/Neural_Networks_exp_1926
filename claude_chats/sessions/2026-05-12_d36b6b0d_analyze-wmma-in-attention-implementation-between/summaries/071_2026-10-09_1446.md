2. Key Technical Concepts:

**SFT loss and gradient flow:**
- Masking: label 65535; global trained-token denominator; backward seed W.
- Gradient reaches prompt positions only through attention (the K/V reads). In the last layer, the prompt feeds only Wk/Wv.
- Pad rows get exactly 0 gradient.
- Tied embedding: the output side touches all 50,304 rows.
- Weight decay is 0.1 on 2-D weights incl. wte (`bluscript_zero_ckpt.cpp:1267` excludes 1-D).

**Batching:**
- v1 = pad to 4096.
- v1.5 = length bucketing.
- v2 = packing + block-diagonal mask.
- Measured: ×1 / ×2.84 / ×3.60 work; v2 has 1,517 rows, 16.3 pads per row, **1–12 chats per row**.
- Best-fit decreasing (BFD) packing; never split a chat.

**Kernel benchmark scope:**
- The loss kernel.
- The embedding backward: bf16 atomicAdd fallback on `dist_side_merge`. Kruthik's `EmbeddingBwdFused` needs the real-N fix.
- v2 attention.
- Q11: BluBLAS M%64 risk.

**Rivals:**

**Evaluation research:**

**Varlen attention designs found:**
- **A — varlen per chat (`cu_seqlens`):**
  - FA2: `BlockInfo`, early exit, per-chat causal n-limit, bounds masking, empty-tile LSE = INF.
  - FA3: `SeqlenInfo`, `offset_q_padded`, prepare kernel sorting longest-first, persistent dynamic scheduler.
  - mem-eff (xFormers in PyTorch): `seqstart`.
  - TE THD: cuDNN ragged offsets or the FA backend.
  - PyTorch `varlen_attn`.
- **B — block-sparse mask:**
  - FlexAttention `BlockMask`, with normal vs full block loops.
  - torchtitan `block_causal` / `packed_document_mask` (`kv_idx >= offsets[document_id[q_idx]]`).
- **Data side:**
  - positions restart per chat; boundaries come from `positions == 0` or `cu_seqlens`;
  - HF puts −100 at chat starts (our labels are already shifted per chat);
  - TRL bfd / bfd_split / wrapped;
  - TE `cu_seqlens_padded`;
  - torchtitan fixed-shape metadata.

**Causal mask facts (from code):**
- Optimized kernels never load or compute tiles fully above the diagonal.
- Diagonal tiles are fully computed, then the upper entries are set to −INFINITY (softmax weight 0).
- The naive PyTorch math path builds a full tril mask, computes the whole Q·Kᵀ and adds −inf.
