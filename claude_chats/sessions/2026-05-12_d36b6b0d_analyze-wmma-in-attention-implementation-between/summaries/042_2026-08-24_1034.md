2. **Key Technical Concepts:**
- SM90 warp-specialized Hopper GEMM: 1 producer + 2 consumer warpgroups, TMA, wgmma/HGMMA, mbarriers, thread-block clusters
- `WGMMA_ROTATE` (WROT): 0 = drain at bottom, 1 = drain before acquire, 2 = drain after acquire
- **§H27z.86 swap rule**: cuBLAS `AxB, r` → ours `BxA, flip(r)`; cuBLAS's `1x2_h` == our `2x1_v`
- **§H27z.74 swizzle**: `granule = row*8 + (row XOR m)`, implemented by `epi_swz_index(row,col,width,span,shift)`
- `EPI_SWIZZLE_BYTES` → `EPI_SPAN = bytes/16`, `EPI_SWZ_SHIFT = 3 - log2(SPAN)`; consistency condition `C_BOX_N == EPI_SPAN*8`
- **§H27z.76**: STSM on a LINEAR layout = 192 conflicts / 3.217 ms vs STS 192 / 3.230 — a TIE. Swizzle is the prerequisite; then stmatrix is worth 1.93× on the store path
- `stmatrix.sync.aligned.m8n8.x4.shared.b16` — lane addressing `stsm_rr = lane&7`, `stsm_am = lane>>3`
- `wgmma_frag_rowcol`: `row = t1 + 8*v1 + 16*t2` (t2 = lane>>5 = warp id), `col = 2*t0 + v0 + 8*v2` (v2 = reg>>2)
- Depth derivation: `LOAD_PIPE_DEPTH = (SMEM_BUDGET(231424) - STORE_BUF_BYTES) / STAGE_BYTES`
- **Depth slope measured −17.65 points/stage going 3→2** (§H27zzs) but only +0.60 going 3→4 on V5 — asymmetric
- `BLUBLAS_PREHEAT_MS` / `BLUBLAS_REF_AFTER` — new harness env controls for measurement-order arms
- nsys `--gpu-metrics-devices --gpu-metrics-frequency=10000` joined to `CUPTI_ACTIVITY_KIND_KERNEL` for per-kernel clock
- Null control technique: two config names compiling to byte-identical binaries give the noise floor for that run
